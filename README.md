# go-cli

Небольшая CLI-программа на Go для изучения основ языка.

Для запуска CLI пропишите:

```bash
go install github.com/sabyrkaworks/go-cli@latest
```

## Commands

- `help`: выводит список доступных команд
- `добавить`: позволяет добавлять что-либо
- `удалить`: позволяет удалить что-либо
- `выйти`: выход из приложения
